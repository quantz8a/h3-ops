quantz8a / h3-ops

ContextDoc → Base → honest HD

h3.c alone: wrong cwd (missing shaders), no revise/lock loop, local upscale that reads like Regenerate-2K. h3-ops is the thin CLI that closes those gaps.

  • cir — compile / validate / revise / emit ContextDoc
  • ops — doctor / gate / GPU lock / run / batch
  • hd — native · upscale_* · cloud_2k (labels stay honest)
pip install -e .
export H3_OPS_H3C_SRC=/path/to/h3.c
export H3_OPS_MODEL_DIR=/path/to/MiniMax-H3
h3ctl doctor
h3ctl run --preset smoke --prompt-file examples/smoke.prompt.txt -o out/smoke.mp4
