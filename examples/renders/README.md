# example renders

Put short demo clips here so the README can link real media (GitHub README cannot play MP4 inline — host a GIF/WebP or link to Pages / release assets).

Suggested names:

| file | what |
|:---|:---|
| `leafcut_native.mp4` | `h3ctl run --preset preview --doc examples/leafcut.cir.json` |
| `leafcut_upscale_1080.mp4` | `h3ctl hd deliver --target upscale_1080` |
| `leafcut_upscale_1080.hd.json` | sidecar claims (`upscale`, not Regenerate-2K) |

Large binaries: prefer a GitHub Release asset + link from README, or force-add a small WebP/GIF under `docs/assets/`.
