一条命令链

Apple Silicon 本机：校验环境 → 结构化提示 → 出片 → 诚实升清。

  1. ops h3ctl doctor 锁 GPU、查 shaders / FL2VA / 竞品进程
  2. cir h3ctl cir compile · validate · revise ContextDoc 为真相；MP4 只是投影
  3. ops h3ctl run --preset smoke|preview 始终 chdir 到 h3.c，默认 --ssd-streaming
  4. hd h3ctl hd deliver --target upscale_1080 sidecar 标明 upscale，不假装 Regenerate-2K
